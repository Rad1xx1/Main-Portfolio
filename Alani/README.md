# Alani — готовый локальный сайт

Открыть двойным щелчком `Открыть сайт.cmd`. Запуск использует свободный локальный порт и открывает браузер. Также можно открыть `index.html` напрямую: сайт работает без сборки и интернета; переходы в меню, WhatsApp и карты требуют сети.

Готовы версии для компьютера и телефона, категории блюд, просмотр фото, мобильная навигация и запрос брони с выбором даты, времени, числа гостей и пожеланий. До перехода в WhatsApp показывается состав запроса; подтверждение брони остаётся за администратором.

## Материалы и проверка

Концепции Image Gen и финальные скриншоты — в `design`. Использованы настоящие фотографии блюд из https://alani.tsqr.me/menu и интерьера из https://2gis.kz/almaty/gallery/firm/70000001045489439. Контакты проверены по https://2gis.kz/almaty/firm/70000001045489439. Фото интерьера: Kristina Petrova / галерея 2ГИС. Разрешение на публичное использование материалов нужно согласовать с владельцами. Это локальная демонстрация, не официальный опубликованный сайт.

Проверено в IAB: загрузка, фильтр «Для компании» → только бешбармак, подготовка брони → верные дата/время/число гостей в ссылке WhatsApp, закрытие диалога, мобильная навигация. Консоль без ошибок. На ширинах 390 и 320 px нет горизонтального переполнения. Сообщения ресторану не отправлялись. JavaScript проходит `node --check`.

Сравнение через view_image с concept-hero: сохранены светлый фон, бирюзовый текст, золотая кнопка, открытая композиция в две колонки, крупный Cormorant, фотография без наложения и закруглённый верх. Тексты первого экрана совпадают. Вместо вымышленного продолжения изображения концепции использованы настоящие фотографии ресторана. На телефоне колонки превращаются в вертикальную композицию с нижней кнопкой брони. Полноэкранный снимок IAB недоступен; сохранены обычные снимки desktop.jpg и mobile.jpg.

Исходники: index.html, styles.css, app.js. Шрифты локальные, лицензии в assets. До передачи ресторану сверить цены, правила обслуживания, расписание, материалы и контакты.
