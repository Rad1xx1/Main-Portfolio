# Итоговая проверка — 1 ноября 2026 года

## Среда и метод

Рабочие сценарии сайта проверены в Browser/IAB по адресу `http://127.0.0.1:4187/`. Контент не пустой, заголовок страницы правильный, ошибок загрузки приложения нет. Скрипты дополнительно прошли `node --check`. Все изображения и шрифты локальные. Финальные файлы снимков сделаны в отдельном headless Playwright/Chrome: IAB после нескольких удачных сессий начал возвращать `Unable to capture screenshot` через оба документированных метода захвата. Проверены стандартный viewport, повторная загрузка и видимость; захват не восстановился. Для изображений использован разрешённый рабочим процессом Frontend App Builder резервный путь, только по HTTP локального сайта, без изменения пользовательских вкладок.

В IAB запрошены ширины 320, 375, 390, 768, 1280 и 1505 px. На всех ширинах `scrollWidth` не превышает `clientWidth`, отсутствующих изображений нет. При запросе 1505×1045 IAB сообщал viewport 1506×1046 из-за масштабирования среды. Финальные снимки Playwright сохранены точно в 1505×1045 и 390×844, полные страницы — с теми же ширинами. Пара 1505×1045 совпадает с нативными размерами основной концепции `concept-hero.png`. Перед захватом подтверждены нужная ширина, загрузка всех изображений и шрифтов; ошибок JavaScript нет.

Основной путь: каталог → изменение площади → фильтр → карточка модели → выбор модели → форма → проверка телефона → предпросмотр запроса. Сообщения не отправлялись, внешний WhatsApp при проверке не открывался.

## Пределы проверки

Проверен HTTP-просмотр в IAB, а не Safari/Firefox или физический телефон. Прямой браузерный тест `file://` не выполнен: IAB разрешает только HTTP/HTTPS. Обход политики не предпринимался. Сайт не использует сборку, fetch, модули или backend и сохраняется как обычный комплект HTML/CSS/JS с относительными локальными ресурсами. Для воспроизводимого просмотра есть `serve.cjs`.

Расчёт мощности предварительный. Карточки — демонстрационная выборка, не полный перенос существующего магазина. Актуальность ассортимента, цены и условия работ должны быть согласованы с компанией. Реальная доставка сообщений, формы исходного сайта, покупка, оплата, CRM и публикация не проверялись и не подключались.
