# Портфолио Хана

Публичная витрина проектов с демо-просмотром прямо на странице. Каталог хранится в Cloudflare D1, приложение работает на Cloudflare Workers. Превью загружаются по запросу из двух публичных репозиториев GitHub:

- https://github.com/Rad1xx1/Main-Portfolio
- https://github.com/Rad1xx1/myportfolio

Сайт не выдаёт демонстрации за оплаченные заказы или подтверждённое сотрудничество.

## Файлы

- index.html — интерфейс портфолио.
- worker.template.js — API каталога, прокси-просмотр проектов и заголовки безопасности.
- schema.sql — схема и начальный список проектов для D1.
- build-worker.mjs — собирает HTML в Worker без сторонних зависимостей.
- dist/worker.js — результат сборки; исключён из Git.

## Обновление интерфейса

После правки index.html запустите node build-worker.mjs. Для изменения карточек отредактируйте schema.sql и синхронизируйте данные с базой D1 отдельно. Сайт использует только read-only API для посетителей.

Публичный адрес: https://han-portfolio.clrp.workers.dev
