# Феликс Алматы

Все материалы проекта собраны в этой папке.

- **felix-web/** — текущий многостраничный сайт: 209 товаров, 12 направлений, галереи и характеристики. Готовые страницы находятся в **felix-web/dist/**.
- **Запустить сайт.cmd** — локальный запуск. Затем откройте **http://127.0.0.1:8770/** в Edge или Chrome. Для остановки сервера — Ctrl+C в его окне.
- **Для показа клиенту/** — актуальные скриншоты и описание первого обращения.
- **Карточка компании/** — контакты и первоначальное исследование.
- **Исследование/** — снимки исходного сайта.
- **Проверка/** — отчёты проверок, скриншоты и результаты мобильной проверки.
- **Архив/** — сохранённые архивы разных этапов. Старые демоверсии не заменяют текущую папку felix-web.
- **felix-site/** — предыдущая одностраничная концепция и дизайн-референсы.

Служебные `.cjs` в корне — инструменты сбора, сборки, проверки и прежней доставки. Если они нужны, запускайте их из этой папки. Для обычного просмотра сайта они не требуются.

Текущая сборка: в felix-web выполните `npm run build`; установка зависимостей не нужна. Проект работает без платных API.

Это локальная концепция для согласования: реальные заявки и оплата не подключены, сайт публично не размещён. До запуска нужно подтвердить ассортимент, условия и права на фотографии с компанией.

Копии материалов в «Документы/Работа» сохранены. Дальнейшая работа ведётся здесь.
