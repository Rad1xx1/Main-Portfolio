# Феликс Алматы — расширенный каталог

Перенесено 209 товаров и 12 направлений исходного сайта. Сборка содержит 233 страниц. Названия, фотографии и 1390 строк характеристик взяты из публичных карточек. Галереи: 1366 уникальных файлов, ошибок загрузки 0.

## Запуск

Откройте «Запустить сайт.cmd», затем http://127.0.0.1:8770. Сервер слушает только этот компьютер; остановка Ctrl+C. Он не принимает заявки. Node.js нужен только для локального сервера и повторной сборки. Зависимости не устанавливаются. Можно открыть dist/index.html напрямую, но для подборки между страницами рекомендуется локальный сервер.

Сборка: npm run build. Запуск: npm start. Папка dist — готовые статические файлы; assets/catalog — изображения с корректными расширениями и типами. Весь каталог и фотогалереи работают без интернета. Основные фото встроены в catalog-data.js, а галереи — в страницы товаров. Изображения не зависят от расположения папки assets при просмотре.

Они распределены по явным названиям: CHAIRMAN KIDS — детские, «Кабинет…» — кабинеты, «Статуэтка…» — аксессуары; основание сохранено в catalog-data.js.

Акустические кабины: раздел сохранён, на исходном сайте он пуст. Товары не придуманы. Рядом есть разделы «Как оформить заявку», «Цены и предложения», «Дилерам» и «Партнёры». Содержимое изложено заново; исходные служебные ошибки и посторонние тексты не копировались.

## Источники и ограничения

Карта старого сайта содержит 209 карточек. Загружено 209, ошибок 0. Ссылки и даты — в import/products.json, соответствие изображений — import/media-registry.json. Технические факты перенесены из таблиц. Полные чужие рекламные тексты не дублировались.

На старом сайте встречаются нулевые цены: они не означают бесплатную продажу. В новом каталоге используется «по запросу»; единственная положительная цена показана только в карточке с пометкой, что это значение старого сайта и его нужно подтвердить. Наличие и гарантийные строки из таблиц — сведения источника, не новое обещание компании.

Фотографии — локальные референсы. Для публикации нужно разрешение владельца на материалы и бренд. Это независимая концепция, не официальный магазин. Метка демо и noindex сохранены. Оплата и реальные заявки не подключены; подборка и TXT остаются локальными.
