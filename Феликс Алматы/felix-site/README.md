# Феликс Алматы — концепция редизайна

Откройте index.html двойным щелчком. Сборка, установка зависимостей и интернет не требуются. Современные Chrome, Edge, Firefox, Safari.

## Реализовано

Адаптивный сайт; шесть реальных коллекций; поиск и фильтры; карточки с источниками; подборка с сохранением после перезапуска; описание задачи; копирование и скачивание списка в TXT; мобильное меню; контакты с корректной ссылкой WhatsApp. Все материалы локальные, сторонние скрипты и аналитика отсутствуют.

## Перед показом

Это независимая локальная демонстрация. Верхняя строка явно это обозначает. Ничего не отправляется компании. Кнопки телефона, почты и WhatsApp запускают соответствующее приложение только при ручном нажатии. Для показа достаточно index.html; before-after.html показывает разницу со старой версией.

## Перед публикацией

1. Получить согласие компании на проект, бренд и использование фотографий. Реестр: assets-sources.json и sources.html.
2. Сверить ассортимент, адрес, контакты, характеристики и цены. В демо стоимость по запросу; не обещаны наличие и сроки.
3. Согласовать способ приёма заявок и подключить настоящий сервер или разрешённый почтовый сервис. Сейчас форма создаёт только локальный черновик, не имитирует успешную отправку.
4. Согласовать политику обработки данных, домен и хостинг. Только после этого убрать noindex и отметку демо.

## Файлы

index.html — страница; styles.css — дизайн; app.js — поведение; products.js — каталог; assets/ — фото; sources.html — источники; before-after.html — сравнение; design/ — концепции и визуальное задание.

Ни платные API, ни LLM при использовании сайта не вызываются.
