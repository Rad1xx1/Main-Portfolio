# Проверка дизайна и поведения

Дата: 1 ноября 2026. Метод: встроенный браузер IAB через cua_repl, живой локальный сервер http://127.0.0.1:8882. Playwright как отдельный браузер не использовался.

## Сверка с концепциями

Исходники: 01-hero-concept.png, 02-menu-concept.png, 03-contact-concept.png. Финальные desktop.jpg, desktop-full.jpg, mobile.jpg и mobile-full.jpg просмотрены через view_image. Главный экран проверен на исходной ширине концепции 1536 px при высоте 1024 px; мобильный — 390×844.

| Что сравнивалось | Результат |
| --- | --- |
| Композиция первого экрана | Сохранены шапка, две колонки, крупный двухстрочный заголовок, две ссылки, адрес и подпись фотографии. |
| Текст | Состав видимого текста первого экрана совпадает со списком в Дизайн.md; дополнительные бейджи и рекламные обещания не добавлены. На мобильном переносы адаптированы. |
| Палитра | Реализованы тёплый фон #f6f2eb, espresso-текст #2d2926, терракотовые кнопки #a65e45 и оливковые элементы. Цветового фильтра поверх фото нет. |
| Типографика | Cormorant для крупных редакционных заголовков и текстового знака; Manrope для интерфейса. Локальные шрифты загружаются; размеры контролов заданы явно. |
| Секции и контейнеры | Сохранены открытые три колонки меню, подписи, ссылка полного меню, оливковая полоса и двухколоночные контакты; на телефоне одна колонка. |
| Изображения | Использованы самостоятельные иллюстративные активы в стилистике концепции. Кадрирование отличается от макетов, как предусмотрено до реализации в Дизайн.md. Растровый интерфейс не используется. |
| Иконки | Тонкие SVG-стрелки, квадратная кнопка мобильного меню, без сторонних декоративных иконок. |
| Адаптация | Убрано горизонтальное переполнение крупного заголовка контактов на 320 px. Исправлены пробелы после переносов строк, скрываемых на телефоне. |

Реализация сверена с выбранной дизайн-концепцией. Материальных неисправленных визуальных дефектов в проверенных состояниях не обнаружено. Осознанные отличия: самостоятельные изображения вместо буквального фото из макета; оливковая секция без выдуманной фотографии интерьера; мобильная навигация как необходимая адаптация. Типографический знак и изображения требуют согласования с кафе перед официальной публикацией.

## Функциональная проверка

| Проверка | Результат |
| --- | --- |
| Идентичность страницы | Верные URL и title; содержимое осмысленное, страница не пустая. |
| Ошибки загрузки и интерфейса | Все четыре вхождения фотографий загружаются; ошибок и предупреждений приложения в консоли IAB нет. Ошибочного framework overlay нет. |
| Переход к меню | «Посмотреть меню» меняет URL на #menu и показывает раздел меню. |
| Мобильная навигация | Кнопка раскрывает меню и меняет aria-expanded на true; выбор «Как нас найти» ведёт к #contacts и закрывает навигацию. |
| Escape | Закрывает раскрытую навигацию, возвращает фокус кнопке. |
| Контакты | Проверены href: tel:+77003504101, https://wa.me/77003504101, Instagram кафе, внешний QR-ресурс и маршрут 2ГИС. Сообщения и звонки не выполнялись. |
| 320 px | clientWidth 305, scrollWidth 305 — горизонтального переполнения нет. |
| 768 px | clientWidth 753, scrollWidth 753 — горизонтального переполнения нет. |
| 1440 px | clientWidth 1425, scrollWidth 1425 — горизонтального переполнения нет. |
| Синтаксис | node --check site.js и node --check server.cjs проходят. |

Разница между шириной окна и clientWidth обусловлена полосой прокрутки. На 390 px визуально проверены первый экран, меню и контакты; сохранена полная мобильная страница.

Ограничения: не проводились реальные звонки или отправка сообщений; работа внешних меню и мессенджеров зависит от их сервисов. Нет календаря и подтверждения бронирования. Отдельно Safari и Firefox не проверялись. Время работы, цены, реальные фотографии и право официальной публикации должны быть согласованы с кафе.
