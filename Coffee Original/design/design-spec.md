# Coffee Original — дизайн демонстрации

Дата: 02.11.2026. Концепции созданы встроенным Image Gen. Рабочее направление выбрано для реализации без отдельного этапа согласования дизайна, так как пользователь одобрил создание проекта.

## Система

- Фон #f4f0e8; текст #33271f; акцент #a45135; olive #747960; атмосфера #e5e6dc; панель #e8e1d4.
- Заголовки Georgia, обычное начертание, плотный межбуквенный интервал. Текст и элементы управления Manrope с локальными латинским и кириллическим файлами.
- Открытая редакционная композиция, линии 1px, прямоугольные кнопки с радиусом 3px, без теней и градиентов.
- Десктоп: поля 4–5vw, ограничение 1600px; hero 44/56, ниже три открытые колонки меню; затем фото/текст атмосферы; список филиалов и панель выбора; тёмный подвал.
- Первый экран: типографический концептуальный знак coffee original.; навигация Меню / Атмосфера / Кофейни; Выбрать кофейню; заголовок Твой день. / Твой кофе. / Твой Original.; описание Для неспешных завтраков, рабочих идей и встреч в Алматы.; Найти свою кофейню / Смотреть меню; подпись Маленькая пауза. Большое удовольствие.; три строки полосы преимуществ. Других видимых заголовков-надписей над hero нет.
- Стрелки — единый SVG northeast, контур 1.5px; поиск — лупа; мобильное меню — две линии; музыка off и Wi-Fi в атмосфере — простые согласованные SVG.
- Фото без оверлея, текстовая подпись вынесена отдельно. Иллюстрации обозначены в alt и подвале. Типографический знак не выдаётся за официальный логотип.

## Интерактивность

- Фильтр Все / Only for Women, поиск адреса, выбранный филиал и панель деталей, раскрытие остальных адресов.
- Выбор меню: отдельные проверенные ссылки Wolt для Байтурсынова и KamiQR для Алатау; не выдавать их за единое меню всей сети.
- Запрос брони: локальная форма даты, времени и гостей → предпросмотр сообщения → самостоятельное открытие WhatsApp конкретного филиала. Никакой автоматической отправки и обещания подтверждённой брони.
- Поиск маршрута по текстовому адресу; не копировать недостоверные координаты исходной карты.
- Приложение: ссылки App Store / Google Play из Taplink.
- Мобильная версия: один столбец, складывающаяся навигация, заголовки 48–60px, кнопки не менее 44px, панель филиала следует после списка, доступные dialog и focus-visible.

## Допустимые уточнения при реализации

- Исходная подпись на фотографии перенесена под фото: контраст и отсутствие оверлея.
- В форме брони и окнах меню/приложения добавлены необходимые поля и пояснения в той же системе. Концепты не показывают эти состояния.
- В подвал добавлена явная пометка об иллюстративных изображениях и ссылка на исходную страницу.
- Часы работы, старые акции, срок сертификата и количество филиалов не выдаются за актуальные для всей сети.
- Гоголя не включена в локальный список из-за расхождения 75/95. Для Радостовца женский формат требует проверки: не включён в фильтр Only for Women до уточнения.
