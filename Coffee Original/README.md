# Coffee Original

Локальный демонстрационный сайт, подготовлен 02.11.2026 после выбора компании пользователем. Заказ компанией не подтверждён. Сайт не опубликован, обращения не отправлялись.

## Открыть

Дважды нажмите `Открыть сайт.cmd`. Адрес локального сервера: http://127.0.0.1:55106/ . При отсутствии Node.js откроется `index.html` напрямую. Все изображения и шрифты локальные; основные функции работают и при открытии файла.

## Что готово

- Адаптивная страница: кофе и завтраки, атмосфера, филиалы.
- Поиск по адресу, фильтр Only for Women, 9 адресов из публичной страницы, раскрытие списка и панель выбранной кофейни.
- Маршрут через поиск адреса в 2ГИС.
- Форма запроса брони: дата, время, число гостей, предпросмотр текста и ссылка на WhatsApp выбранного филиала. Отправка только самим посетителем. Подтверждение брони требует ответа администратора.
- Меню на Wolt для Байтурсынова и KamiQR для Алатау; страницы явно подписаны по филиалам.
- Ссылки на Instagram и приложение для iOS / Android.
- Навигация с клавиатуры, диалоги с Escape и возвратом фокуса, поддержка reduced motion, локальные шрифты, WebP-изображения.
