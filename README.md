## Просмотр

Скачайте репозиторий или клонируйте его. В папках проектов есть инструкции и файлы локального запуска `.cmd`. Для Феликс Алматы используйте `Запустить сайт.cmd`; актуальная сборка находится в `felix-web/dist`. Ссылки выше открывают исходные файлы на GitHub, а не работающие сайты. GitHub Pages не настроен.

В папках `design` и материалах проверки сохранены концепции и скриншоты. Зависимости, дублирующие ZIP-архивы и внутренние черновики предложений в репозиторий не входят.

В некоторых проектах использованы материалы из публичных источников; сведения об источниках сохранены рядом с проектами.
